# v1.48.0.0 upstream port audit

Date: 2026-10-10

Branch: `codex/v1.48.0.0-implementation`

Fork baseline: `codex/v1.47.0.31-implementation` (`d5c2d523`)

Upstream range: `dograh-v1.47.0` (`d91e4f5a`) to `dograh-v1.48.0`
(`5db59b9a`)

## Decision

The upstream release changes 314 paths. The fork has 496 paths changed from
the upstream 1.47.0 baseline, with 131 path intersections. The port therefore
uses selective changes only; it does not merge or rebase the upstream branch.

Imported:

- `b87ea331` — add the isolated `canadacentral` Azure Speech region option.
  The file was not modified by the CALMOS v1.47.0.31 delta and the change does
  not affect Sakinah, call lifecycle, persistence, storage, or the UI.

Skipped:

- Answer-supervisor, text-chat, watchdog, idle-controller, Gemini reconnect,
  handoff, and Pipecat runtime changes (`55643fa6`, `8d285e96`, `17abfb5e`,
  `8a49677b`, `fa1df112`, `7ac9fef8`, and related commits). These alter shared
  call execution paths and overlap CALMOS runtime behavior.
- MiniMax/TTS cache, TTS retry, EOT, Cartesia, Pipecat 1.12, and Docker/NLTK
  changes (`7ca8d946`, `ba09ef5c`, `cba74230`, `a6aee063`, `54674186`,
  `3296d375`, `22ddba51`). These change shared audio/runtime dependencies and
  could affect live calls or the fork's storage/audio behavior.
- Telephony, SIP, transfer, Telnyx, MinIO, and recording-router changes
  (`cb7f614a`, `4332bcce`, `caee6ac6`, `11e82c98`, `0663fedf`, `93ed5c33`,
  `75a299e2`, `e58584ba`). These affect deployment, provider, recording, or
  transfer behavior used by CALMOS.
- Workflow, campaign, knowledge-base, event-banner, generated-client, and
  dependency changes (`20a1a0ac`, `c18b367a`, `05ffd677`, `1e47eb54`,
  `71bc446c`, `2b0eb026`, `0d5b68fb`, `843e9a1f`, `33798b83`, and related
  commits). They touch shared API/UI contracts or fork-modified paths and are
  not isolated from CALMOS behavior.
- MCP call-history tools (`130513aa`) because they modify workflow-run and
  artifact paths that contain CALMOS persistence and signed-storage logic.
- Billing timezone and billing-filter changes (`234c73a8`, `843e9a1f`). The
  timezone commit depends on the upstream billing-filter context and produced
  a conflict in the fork's billing route; the sequence was skipped rather than
  importing unrelated billing behavior.
- Provider/configuration, observability, service-registry, SDK, documentation,
  and release-only changes where they touched shared fork paths or were not
  needed for CALMOS (`9933b880`, `3e66307b`, `4e6cb22b`, `7d5b7e5f`,
  `33798b83`, `a873fbe9`, `33d41088`, `06bf2ab6`, and release metadata).

The upstream merge commits were history-only and added no independent change.
The upstream release metadata was not copied because the white-label line uses
the four-component version `1.48.0.0`.

## Preservation checklist

- Sakinah recognised-caller continuity, consent refusal/reenablement, and
  privacy boundaries remain on the v1.47.0.31 implementation.
- PIN continuity, call/run persistence, CALM scoring, S3/MinIO replication,
  data explorer behavior, WhatsApp support, and single-worker deployment were
  not modified by the upstream port.
- No database migration was added.
