## Live call checklist

The following requires the team phones and the deployed database, so it is
recorded for the deployment run rather than claimed as completed locally:

1. On a recognised phone, say yes and discuss work for at least six turns.
   Confirm the run has memories and an AI summary.
2. Call again and confirm the opening references work without names, health
   details, or “welcome back”.
3. On the next call, discuss a new topic and say no. Confirm zero memories and
   no continuity summary for that run.
4. Call again and confirm the earlier work call is referenced, never the declined
   call.
5. Say yes again and confirm later calls can save and recall new memories.
6. Use a new phone and confirm there is no historic reference.
7. Set `SAKINAH_RECOGNISED_CONTINUITY=false`, restart the API, and confirm
   recognised calls behave as they did before v1.47.0.31.

Use the release query from the context brief to check only consent, summary
presence, and memory counts; do not export personal content.

No database migration is required. Back up the database before deployment, tag
the API/UI images as `1.47.0.31`, and keep the `v1.47.0.30` branch/tag
available for rollback.
